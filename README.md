# Mamora

Sounds to unwind to. Pick relaxing sounds from a spinning ring, combine up to six in the mixer, then save, share or download your mix.

- Every sound is synthesised live in the browser and loops seamlessly, so there are no audio files to license.
- Photos from [Pexels](https://www.pexels.com), used under the free Pexels licence.
- It's a single static page (`index.html`) with no build step.

## Run locally

```bash
python3 -m http.server 5178
```

Then open http://localhost:5178.
